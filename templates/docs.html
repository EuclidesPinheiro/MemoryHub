API Documentation

Complete reference for the MemoryHub REST API.

Base URL

http://localhost:8000/api

Endpoints

POST /memories

Create a new memory item.

Request Body

{
  "app_id": "my-app",         // Required
  "user_id": "user-123",      // Optional
  "namespace": "default",     // Optional, default: "default"
  "content": "Memory text",   // Required
  "tags": ["tag1", "tag2"],   // Optional
  "ttl_seconds": 86400        // Optional, time-to-live
}
GET /memories

List all memories with optional filters.

Query Parameters

  • app_id - Filter by application ID
  • user_id - Filter by user ID
  • namespace - Filter by namespace
  • q - Search in content and tags
  • limit - Max results (default: 50)
GET /memories/{id}

Get a specific memory by ID.

DELETE /memories/{id}

Delete a memory by ID.
